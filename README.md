# Sales-Trend-Analysis-Using-PostgreSQL

## Project Overview

This project analyzes e-commerce sales data using PostgreSQL aggregation functions to identify monthly sales trends, revenue patterns, and order volume. The analysis helps understand business performance over time by grouping sales data by month and year.

## Objective

The objective of this project is to:

* Analyze monthly revenue trends
* Analyze monthly order volume
* Identify high-performing sales periods
* Use date functions and grouping operations for business analysis

## Dataset

Dataset: E-commerce Sales Transactions Dataset

The dataset contains 34,500 sales records with the following key columns:

* order_id
* customer_id
* product_id
* category
* price
* discount
* quantity
* payment_method
* order_date
* total_amount
* shipping_cost
* profit_margin
* region
* returned
* customer_gender
